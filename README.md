# Insecure Cryptography CTF

## Overview:

This is a 3-level Capture-The_Flag challenge designed to test your scripting skills and understanding of cryptographic concepts. Your goal is to find the "randomly" generated password in each of the levels, then use it to decrypt the flag file.


## Installation & Setup

(This guide assumes a Linux environment.)

1. Clone the repository.
2. ``cd`` into the root directory.
3. Run ```pip install -r requirements.txt```
4. Run ```python3 your_chosen_level.py``` to begin any level of the challenge you desire. You may start at level 1 and work up to level 3, or tackle the harder tasks first. 

Note: Inspecting the source code for this challenge is not only allowed but encouraged.
